# CertDesk

CertDesk — информационная система контроля сертификатов электронной подписи и машиночитаемых доверенностей сотрудников.

## Стек

- C#
- Windows Forms
- .NET 8 Windows Desktop
- SQLite
- ADO.NET через Microsoft.Data.Sqlite
- CSV и XLSX-отчеты через ClosedXML

## Как открыть и запустить

1. Откройте `WinFormsApp16.sln` в Visual Studio 2022.
2. Дождитесь восстановления NuGet-пакетов.
3. Нажмите **Start** / **F5**.

## Тестовые пользователи

- `admin` / `admin123` — администратор.
- `spec` / `spec123` — специалист.
- `view` / `view123` — просмотр.

Пароли хранятся в базе только как PBKDF2-хеши.

## Данные приложения

- База данных создается автоматически: `DataFiles/certdesk.db` рядом с исполняемым файлом.
- Отчеты создаются в `ReportsOutput/`.
- Резервные копии создаются в `Backups/`.

## Разделы

- Главная: показатели и записи, требующие внимания.
- Сертификаты: создание, изменение, отзыв, архивирование и экспорт.
- МЧД: создание, изменение, отзыв, архивирование и экспорт.
- Токены: учет токенов, выдача, возврат, повреждение и списание.
- Сотрудники: создание, изменение и архивирование сотрудников.
- Отчеты: CSV и XLSX-выгрузки.
- Аудит: журнал действий администратора и пользователей.
- Резервная копия: копирование текущей SQLite-базы.

## Требования

Windows 10/11, Visual Studio 2022 и установленный .NET 8 Desktop Runtime/SDK.
